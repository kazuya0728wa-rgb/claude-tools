# Google Sheets / GAS 管理ツール

## ディレクトリ構成

```
sheets/
├── auth.py              # OAuth2 認証（共通）
├── config.py            # 現在のアクティブプロジェクト設定
├── gas_ops.py           # GAS API CLI（共通）
├── sheets_ops.py        # Sheets API CLI（共通）
├── nippo/               # 日報提出&ランキングシート
│   ├── config.py        # 専用設定（SPREADSHEET_ID, GAS_SCRIPT_ID）
│   ├── コード.js         # GAS本体
│   ├── フォーム.html      # 日報フォーム（クライアントHTML）
│   └── push.py          # 専用pushスクリプト
├── kadou/               # 稼働管理表_3Link
│   ├── config.py        # 専用設定
│   ├── コード.js         # GAS本体
│   ├── フォーム.html      # 稼働管理フォーム
│   └── push.py          # 専用pushスクリプト
├── gas_snapshot.js      # 月次スナップショット用GAS（参照用）
└── gas_upload/          # 旧バックアップ（参照用）
```

## GASへの変更手順

### 1. 対象プロジェクトのファイルを編集

- 日報の変更 → `nippo/コード.js`, `nippo/フォーム.html`
- 稼働管理の変更 → `kadou/コード.js`, `kadou/フォーム.html`

### 2. 専用pushスクリプトでpush

```bash
# 日報ランキングシートにpush
python nippo/push.py

# 稼働管理表にpush
python kadou/push.py
```

### 3. GASを再デプロイ（ユーザーが操作）

スプレッドシート →「拡張機能」→「Apps Script」→「デプロイ」→「デプロイを管理」→ 鉛筆アイコン →「バージョン: 新バージョン」→「デプロイ」

## 日報提出&ランキングシート

### シート構成

#### 日報提出（15列）

| 列 | 項目 | 備考 |
|---|---|---|
| A | 日付 | |
| B | 氏名 | |
| C | 案件名 | 複数選択時は「・」で結合 |
| D | 商談数 | |
| E | キャンセル・不着席 | |
| F | 継続・２回目 | |
| G | 成約数 | |
| H | 失注数 | |
| I | 損切数 | |
| J | 失注理由/録画URL | |
| K | 今回決済金額 | 成約ブロックの合計 |
| L | 商品総額 | 成約ブロックの合計 |
| M | 残額（自動） | ARRAYFORMULA |
| N | 入力時刻（自動） | GASで自動設定 |
| O | メモ | |

#### 成約管理（10列）

| 列 | 項目 | 備考 |
|---|---|---|
| A | 日付 | |
| B | 氏名 | |
| C | 案件名 | |
| D | 決済方法 | |
| E | 今回決済金額 | |
| F | 商品総額 | |
| G | 残額（自動） | ARRAYFORMULA |
| H | 残額決済済 | チェックボックス |
| I | 残額決済期限 | |
| J | 入力時刻（自動） | GASで自動設定 |

#### セールスメンバー

| 列 | 項目 | 備考 |
|---|---|---|
| A | 氏名 | フォームの氏名リストに反映 |
| C | 稼働状況 | `稼働` のみフォームに表示 |
| D | 案件名 | フォームの案件名チェックボックスに反映 |

#### 今月のランキング
- 今月の成約数・売上を自動集計

### フォームのバリデーション

| 条件 | エラーメッセージ |
|---|---|
| 案件名が未選択 | 案件名を1つ以上選択してください |
| 商談数 ≠ キャンセル+成約+失注+損切 | 合計と一致しません |
| 成約数 ≠ 成約ブロックの件数 | 成約情報の件数が一致しません |

## スプレッドシートを直接操作するコマンド

config.py のアクティブプロジェクトに対して操作します。

```bash
# セルを読む
python sheets_ops.py read --range "日報提出!A1:O3"

# 値を書き込む
python sheets_ops.py write --range "成約管理!A2" --value "2026/03/22"

# 数式を書き込む
python sheets_ops.py formula --range "成約管理!G2" --formula "=ARRAYFORMULA(...)"
```
