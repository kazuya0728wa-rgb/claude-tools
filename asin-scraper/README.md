# Amazon ASIN 付属品調査ツール (Amazon ASIN Accessory Scraper)

このプロジェクトは、Googleスプレッドシートの「商品リスト」シートを対象に、ASINからAmazon.co.jpやメーカー公式サイトの製品情報・取扱説明書を自動調査し、付属品情報を抽出してスプレッドシートに追記するPythonツールです。

## 主な機能と仕様
- **対象シート**: Googleスプレッドシートの「商品リスト」シート（2行目以降）
- **対象列**:
  - `J列`: ASIN（入力）
  - `BC列`: 付属品（出力・カンマ区切り）
  - `BD列`: 根拠URL（出力・改行区切り）
- **処理条件**:
  - `BC列` および `BD列` が両方とも空欄の行のみを処理します。手入力データの保護のため、既に値がある行は上書きしません。
  - `ASIN` が空欄、または不正な形式（10桁の英数字以外など）の場合はスキップします。
- **調査ロジック優先順位**:
  1. メーカー公式説明書
  2. メーカー公式製品ページ
  3. Amazon商品ページ
  4. 外部説明書サイト
- **出力ルール**:
  - 付属品の名称は元の記載をそのまま使用します。推測による補完は行いません。
  - 「別売品」「推奨アクセサリ」「対応アクセサリ」などは付属品に含めません。
  - 説明書が見つからない、または見つかっても付属品の記載がない場合は、`BC列` に「説明書未検出」と記入し、`BD列` は空欄にします。
- **実行方法**:
  - 手動実行を想定したスクリプトとして構成されます。
